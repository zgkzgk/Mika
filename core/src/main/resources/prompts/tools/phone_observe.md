Look at the phone's current screen (the virtual display). Returns the foreground app, all visible elements, and the full accessibility tree grouped by window, with parent-child relationships and control states. Use the tree to identify which item or dialog owns a control, then pass that control's ref and snapshotId to {{tap}}. When the tree is missing much of the screen, treeQuality says so and visibleText adds on-device OCR text with tap centers (a screenshot too, if you can view images); repeat reads return only what changed in visibleText (new/gone/moved, or {"unchanged":true}), pass full:true to get the full text again. If the target is still missing or ambiguous, request {{screenshot}} or {{find_visually}}.
